# Vibe Terminal

Linux, Windows, macOS를 지원하는 빠른 크로스플랫폼 SSH 터미널 앱입니다.

[English](README.md)

## 주요 기능

- **완전한 터미널 에뮬레이션** — xterm 호환 렌더링과 ANSI 컬러를 지원하며, 줌인/줌아웃으로 글자 크기를 조정할 수 있습니다.
- **호스트 및 세션 관리** — 세션 그룹으로 연결을 정리하고, 한 번의 클릭으로 재접속하며, 여러 세션을 동시에 열어둘 수 있습니다.
- **탭 그룹** — 브라우저 세로 탭처럼 작업공간 안의 세션을 이름·색상이 있는 그룹으로 묶고, 접거나 드래그로 넣고 뺄 수 있습니다.
- **접힌 패널의 세션 목록** — 좌측 패널을 접어도 세션을 아이콘으로 보여 주며 연결 상태와 Agent 상태를 함께 표시합니다.
- **세션 정보 툴팁** — 세션에 마우스를 올리면 연결 종류·주소·점프 호스트·OS·상태를 보여 줍니다.
- **SSH 점프 호스트** — 점프 호스트를 거쳐 최종 SSH 대상에 접속합니다. 이전에 저장한 Kubernetes 경유 호스트는 계속 연결할 수 있습니다.
- **로컬 터미널** — SSH 세션과 함께 로컬 셸을 열고, 함께 배포되는 데몬으로 앱 재시작 후에도 로컬 세션을 이어갑니다.
- **스니펫 패널** — 자주 쓰는 명령어를 저장하고 재사용합니다.
- **AI Chat 패널** — 작업 중에 AI와 대화할 수 있는 사이드 패널입니다.
- **GUI 문서 모드** — 터미널 출력을 선택 가능한 글로 읽고, 코드 블록을 복사하거나 웹 링크를 열며 별도 입력창에서 메시지를 작성합니다.
- **Agent Chat** — 사이드 패널에서 세션 속 CLI Agent에게 작업을 맡기고 예약 루틴을 실행합니다.
- **Agent 자율사용** — 지원되는 CLI Agent가 끊기거나 사용량 한도에 걸린 뒤 이어서 진행하고, 위험하지 않은 확인 요청을 한 번 승인하도록 켤 수 있습니다.
- **퍼피 ReCap** — AI 연결을 설정하면 🐶 버튼으로 세션에서 진행한 작업을 3줄로 요약해 보여 줍니다.
- **AI 답변 제안** — 연결한 AI에 답변 후보를 요청하거나, 지원되는 Agent가 입력을 기다릴 때 자동으로 제안을 받을 수 있습니다. 답변은 후보를 선택했을 때만 전송합니다.
- **터치 제어** — 마우스 입력을 지원하는 터미널 프로그램에 탭·클릭을 전달하도록 켤 수 있으며 스크롤과 롱프레스 글자 선택을 유지합니다.
- **제스처 단축키** — 두 번 탭과 더블 클릭에 Tab·키 조합 등을 지정할 수 있습니다. 별도 설정 전에는 기존 선택 동작을 유지합니다.
- **메모 패널** — 터미널 세션 옆에서 바로 메모를 남길 수 있습니다.
- **Community 패널** — 다른 사용자들과 자료를 공유하고 탐색합니다.
- **CLI 도구 연동** — 시스템에 Claude Code, Codex, OpenCode가 설치되어 있으면 관련 설정을 자동으로 노출합니다.
- **안전한 자격증명 저장** — 호스트 자격증명은 OS 레벨 보안 저장소에 저장됩니다.
- **이미지 붙여넣기** — 지원되는 전송 방식에 이미지를 바로 붙여넣을 수 있습니다.
- **적응형 엣지 패널** — 접을 수 있는 사이드 드로어로 데스크톱과 좁은 창에서도 인터페이스가 복잡해지지 않습니다.

## 시작하기

CI 및 릴리즈 빌드와 같은 Flutter **3.47.2**를 사용합니다.

```sh
flutter pub get
flutter analyze
```

### 빌드

```sh
# Linux
flutter build linux --release

# Windows
flutter build windows --release

# macOS
flutter build macos --release
```

각 플랫폼의 빌드된 바이너리는 [Releases](../../releases) 페이지에서 받을 수 있습니다.
