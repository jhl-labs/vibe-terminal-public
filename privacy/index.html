1. 기기에 저장하는 정보와 이용 목적

SSH 연결, 작업 복원 및 사용자가 선택한 부가 기능을 제공하기 위해 다음 정보를 기기 안에서 처리할 수 있습니다.

  • 호스트 별칭·주소·포트·사용자명·접속 설정, 신뢰한 호스트키 지문
  • SSH 비밀번호·개인키·암호문구, AI 및 GitHub 인증 토큰
  • 터미널 화면·세션 기록·명령과 출력·작업 경로, 스니펫·메모·설정
  • AI 대화·프롬프트와 전달한 텍스트 컨텍스트, AI 제공자·모델·접속 주소

인증 비밀은 운영체제 보안 저장소를 사용합니다. 일반 설정과 작업 데이터는 앱의 로컬 저장소에 보관하며, 모든 로컬 데이터가 별도로 암호화되어 있다고 의미하지는 않습니다. Core 이용을 위한 개발자 운영 계정 가입은 요구하지 않습니다.

2. 네트워크 전송과 제3자 서비스

개발자는 SSH 인증 정보나 터미널 내용을 별도 수집 서버로 자동 전송하거나 판매하지 않습니다. 다음 기능을 사용하면 필요한 정보가 해당 수신자에게 전달됩니다.

기능·수신자전송되는 정보·목적
사용자가 선택한 SSH 서버인증 방식에 필요한 정보, 명령·터미널 입출력 및 사용자가 요청한 파일 내용. SSH 접속과 원격 작업에 사용합니다. 서버 운영자는 접속 주소와 활동을 기록할 수 있습니다.
선택적 AI 기능
OpenAI·Google Gemini·Anthropic 또는 지정한 호환 서버		질문·대화, 터미널 화면·명령·경로 및 기능 설정이나 요청에 따라 추가되는 세션 로그 텍스트, 인증에 필요한 API 토큰. 답변 생성·작업 보조에 사용합니다. 현재 Core AI Chat은 텍스트 요청을 사용하며 파일·이미지를 직접 첨부하는 업로드 기능은 제공하지 않습니다. 파일 내용도 붙여넣거나 터미널 출력·로그에 포함되면 텍스트로 전송될 수 있으므로 확인하세요.
선택적 GitHub·GitHub Enterprise 동기화인증 정보와 저장소 지정, 사용자가 설정한 동기화 데이터. 전체 백업은 호스트·메모·설정과 인증 비밀을 포함할 수 있으며 동기화 암호로 암호화한 스냅샷으로 전송합니다. 원격 사본과 저장소 접근 권한은 사용자가 관리합니다.
선택적 GitHub Gist·커뮤니티직접 내보낸 스니펫, 직접 작성한 Issues·Discussions의 제목·본문, 조회 요청과 GitHub 인증 정보. 스니펫 Gist는 별도의 전체 백업 암호화와 다릅니다. 공개 범위와 내용을 확인하세요. 공개 게시물은 다른 사용자도 볼 수 있습니다.
GitHub 업데이트·릴리즈 확인릴리즈 조회 요청과 버전 비교에 필요한 공개 릴리즈 정보. GitHub는 요청 처리 과정에서 접속 IP·요청 시각·앱의 User-Agent 등 통신 정보를 처리할 수 있습니다. 자동 업데이트 확인은 앱 설정에서 관리할 수 있습니다.

사용자가 실행한 외부 CLI·명령·링크도 해당 서비스와 통신할 수 있습니다. 외부 서비스의 보관·삭제·국외 처리 조건은 해당 제공자의 정책과 사용자 계정 설정에 따릅니다. 제공자에 따라 데이터가 사용자의 거주 국가 밖에서 처리될 수 있으며, 기능을 사용하지 않거나 연결을 해제해 해당 선택적 전송을 중지할 수 있습니다.

관련 정책: OpenAI · Google · Anthropic · GitHub. 직접 지정한 서버에는 그 운영자의 정책이 적용됩니다.

3. 권한과 보안

네트워크 권한은 SSH와 선택한 외부 서비스 접속에 사용합니다. Android 포그라운드 서비스·알림·절전 방지 기능은 사용자가 시작한 SSH 연결을 백그라운드에서도 유지하고 상태를 표시하기 위한 것입니다. 파일·클립보드 기능은 사용자가 요청한 가져오기·내보내기·붙여넣기 등에 사용합니다.

SSH 통신 암호화, 호스트키 확인, 운영체제 보안 저장소를 사용합니다. Android 배포 구성에서는 앱 데이터의 시스템 백업·기기 간 자동 추출을 제한합니다. 사용자가 직접 내보낸 파일, 원격 백업 또는 서버에 보낸 데이터까지 삭제하거나 통제하지는 않습니다. 직접 설정한 외부 서버의 전송 보안도 확인하세요.

4. 보관 기간과 삭제 방법

  • 기기 내 호스트·키·스니펫·메모·대화·기록은 해당 기능의 삭제 동작이나 앱 데이터 초기화 전까지, 또는 앱의 기록 보관 설정에 따라 유지될 수 있습니다.
  • 항목을 삭제해도 다른 호스트에서 공유하는 인증 정보·키나 별도 작업 기록이 남을 수 있습니다. 필요 없는 인증 정보·키·대화·기록도 해당 화면에서 별도로 정리하세요.
  • Android에서는 시스템 설정의 앱 저장공간에서 데이터 삭제를 하거나 앱을 제거하여 앱 전용 로컬 데이터를 정리할 수 있습니다.
  • GitHub 저장소·Gist·게시물·외부 AI 서비스·SSH 서버의 데이터와 직접 내보낸 파일은 앱 제거로 삭제되지 않습니다. 해당 서비스나 파일 저장 위치에서 별도로 삭제해야 하며, Git 이력과 제공자 백업에 이전 내용이 남을 수 있습니다.

개발자는 기기에만 있는 SSH 자격증명이나 작업 기록을 원격으로 열람·복구·삭제할 수 없습니다.
