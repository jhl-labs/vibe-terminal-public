Vibe Terminal Pro

Core의 SSH 터미널·화면 분할·작업 이어가기·스니펫·메모·AI Chat·GitHub 동기화를 모두 담고, 원격 파일과 터널, 여러 에이전트와 함께 일하는 도구를 더한 에디션입니다.

향후 공개 예정

Pro는 향후 공개할 예정입니다. 지금 바로 사용할 수 있는 앱은 무료 Vibe Terminal Core입니다.

Agent Chat

여러 CLI 에이전트에게 역할을 나눠 맡기고, 대화·예약·반복 작업과 우편함으로 함께 일하게 합니다.

SFTP와 포트 포워딩

원격 파일을 탐색·전송하고, SSH 터널로 서버 안의 서비스에 바로 연결합니다.

X11 · 브라우저 · Vault

서버의 GUI 앱과 웹 페이지를 터미널 옆 패널에서 보고, 자주 쓰는 비밀값은 잠금 가능한 Vault에 모읍니다.

AI 루틴과 Agent 자율 사용

예약 루틴, 세션 변화를 지켜보는 감시, 끊기거나 사용량 한도로 멈춘 에이전트 작업의 자동 재개를 제공합니다.

커스텀 앱

나만의 작업 패널을 만들어 작업공간에 붙입니다.

서버 작업 공유

다른 기기에서 연 tmux 작업을 같은 이름의 탭으로 열어 여러 기기에서 동시에 이어 씁니다.

Pro 데이터 처리 안내

Pro의 원격 파일·터널·에이전트 작업은 Core와 데이터 처리 범위가 다릅니다. 자세한 내용은 Pro 전용 개인정보처리방침에서 확인하세요.
