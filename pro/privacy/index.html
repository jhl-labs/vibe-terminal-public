1. 기기에 저장하는 정보와 이용 목적

SSH 연결, 작업 복원 및 사용자가 선택한 부가 기능을 제공하기 위해 다음 정보를 기기 안에서 처리할 수 있습니다.

  • 호스트 별칭·주소·포트·사용자명·접속 설정, 신뢰한 호스트키 지문
  • SSH 비밀번호·개인키·암호문구, AI 및 GitHub 인증 토큰
  • 터미널 화면·세션 기록·명령과 출력·작업 경로, 스니펫·메모·설정
  • AI 대화·프롬프트·선택한 파일이나 이미지, AI 제공자·모델·접속 주소

인증 비밀은 운영체제 보안 저장소를 사용합니다. 일반 설정과 작업 데이터는 앱의 로컬 저장소에 보관하며, 모든 로컬 데이터가 별도로 암호화되어 있다고 의미하지는 않습니다.

2. 네트워크 전송과 제3자 서비스

개발자는 SSH 인증 정보나 터미널 내용을 별도 수집 서버로 자동 전송하거나 판매하지 않습니다. 다음 기능을 사용하면 필요한 정보가 해당 수신자에게 전달됩니다.

기능·수신자전송되는 정보·목적
사용자가 선택한 SSH 서버인증 방식에 필요한 정보, 명령·터미널 입출력 및 사용자가 요청한 파일 내용. SSH 접속과 원격 작업에 사용합니다. 서버 운영자는 접속 주소와 활동을 기록할 수 있습니다.
선택적 AI 기능
OpenAI·Google Gemini·Anthropic 또는 지정한 호환 서버		질문·대화, 기능 실행 시 선택하거나 컨텍스트로 포함된 터미널 출력·명령·경로·파일·이미지, 인증에 필요한 API 토큰. 답변 생성·작업 보조에 사용합니다. 컨텍스트에 민감한 정보가 포함될 수 있으므로 전송할 내용을 확인하세요.
선택적 GitHub·GitHub Enterprise 동기화인증 정보와 저장소 지정, 사용자가 설정한 동기화 데이터. 전체 백업은 호스트·메모·설정과 인증 비밀을 포함할 수 있으며 동기화 암호로 암호화한 스냅샷으로 전송합니다. 원격 사본과 저장소 접근 권한은 사용자가 관리합니다.
선택적 GitHub Gist·커뮤니티직접 내보낸 스니펫, 게시물·댓글·첨부 내용과 GitHub 인증 정보. 스니펫 Gist는 별도의 전체 백업 암호화와 다릅니다. 공개 범위와 내용을 확인하세요. 공개 게시물은 다른 사용자도 볼 수 있습니다.

사용자가 실행한 외부 CLI·명령·링크도 해당 서비스와 통신할 수 있습니다. 외부 서비스의 보관·삭제·국외 처리 조건은 해당 제공자의 정책과 사용자 계정 설정에 따릅니다. 제공자에 따라 데이터가 사용자의 거주 국가 밖에서 처리될 수 있으며, 기능을 사용하지 않거나 연결을 해제해 해당 선택적 전송을 중지할 수 있습니다.

관련 정책: OpenAI · Google · Anthropic · GitHub. 직접 지정한 서버에는 그 운영자의 정책이 적용됩니다.

3. Pro 추가 도구의 데이터 처리

SFTP는 사용자가 선택한 서버·경로와 파일 내용·파일명·메타데이터를 파일 탐색·전송에 사용합니다. 포트 포워딩은 설정한 대상의 통신을 SSH 터널로 전달하며 대상 서비스에도 관련 요청이 도달합니다. Vault와 작업 패널은 사용자가 저장하거나 가져온 내용·접속 설정을 해당 기능에 사용합니다.

Agent Chat·작업 조율·자율사용·AI 루틴·감시 기능은 선택한 명령, 작업 경로, 대화와 터미널·파일 컨텍스트를 처리하고 설정한 AI 제공자·CLI·서버에 전송하거나 명령을 실행할 수 있습니다. 예약·자동 실행을 포함한 전송 범위와 작업 권한은 사용자가 설정합니다. 사용하지 않는 자동화는 중지하고 민감한 컨텍스트를 점검하세요. 브라우저·사용자 정의 앱·X11 등의 연결 대상도 자체적으로 데이터를 처리할 수 있습니다. 지원 기능은 플랫폼과 빌드 구성에 따라 다릅니다.

4. 모바일 진단·사용 통계·공지 알림

Android·iOS에서 Firebase가 활성화된 Pro 빌드는 사용자의 진단·알림 설정에 따라 다음 서비스를 사용합니다. 데스크톱에 같은 Firebase 수집이 적용된다고 의미하지 않습니다. 광고 SDK로 사용하지 않으며 광고 저장·광고 사용자 데이터·개인 맞춤 광고 동의는 비활성으로 설정합니다.

  • Firebase Crashlytics: 오류 보고가 켜져 있으면 오류·스택 추적, 앱·운영체제·기기 진단 정보와 SDK 설치 식별자 등을 안정성 개선에 처리합니다. 오류 메시지의 민감 정보 제거를 시도하지만 모든 오류에서 완전한 제거를 보장하지는 않습니다.
  • Firebase Analytics: 사용 통계가 켜져 있으면 세션 종류, 분할 수, AI 제공자·기능 실행 등 정해진 사용 이벤트와 SDK의 앱 인스턴스·기기·앱 정보를 사용성 개선에 처리합니다. 터미널 본문·SSH 비밀을 사용 이벤트로 의도적으로 전송하지 않습니다.
  • Firebase Cloud Messaging: 공지 알림이 켜져 있으면 SDK 설치 식별자·등록 토큰·공지 주제 구독 등 알림 전달 정보를 Google이 처리합니다. 앱이 등록 토큰을 별도 개발자 서버로 업로드하지 않는 것과 Google이 토큰을 처리하는 것은 구분됩니다.

설정의 진단·알림 항목에서 오류 보고·사용 통계·공지 알림을 각각 끌 수 있습니다. 알림을 끄면 자동 초기화와 주제 구독을 해제하고 등록 토큰 삭제를 요청합니다. 설정을 끄는 것은 이미 전송된 자료의 즉시 삭제를 의미하지 않습니다. 제공자의 처리·보관·삭제 조건은 Firebase 개인정보 보호 안내와 Google 개인정보처리방침에 따르며 국외 처리가 발생할 수 있습니다.

5. 권한과 보안

네트워크 권한은 SSH와 선택한 외부 서비스 접속에 사용합니다. Android 포그라운드 서비스·알림·절전 방지 기능은 사용자가 시작한 SSH 연결을 백그라운드에서도 유지하고 상태를 표시하기 위한 것입니다. 파일·클립보드 기능은 사용자가 요청한 가져오기·내보내기·붙여넣기 등에 사용합니다.

SSH 통신 암호화, 호스트키 확인, 운영체제 보안 저장소를 사용합니다. Android 배포 구성에서는 앱 데이터의 시스템 백업·기기 간 자동 추출을 제한합니다. 사용자가 직접 내보낸 파일, 원격 백업 또는 서버에 보낸 데이터까지 삭제하거나 통제하지는 않습니다. 직접 설정한 외부 서버의 전송 보안도 확인하세요.

6. 보관 기간과 삭제 방법

  • 기기 내 호스트·키·스니펫·메모·대화·기록은 해당 기능의 삭제 동작이나 앱 데이터 초기화 전까지, 또는 앱의 기록 보관 설정에 따라 유지될 수 있습니다.
  • 항목을 삭제해도 다른 호스트에서 공유하는 인증 정보·키나 별도 작업 기록이 남을 수 있습니다. 필요 없는 인증 정보·키·대화·기록도 해당 화면에서 별도로 정리하세요.
  • Android에서는 시스템 설정의 앱 저장공간에서 데이터 삭제를 하거나 앱을 제거하여 앱 전용 로컬 데이터를 정리할 수 있습니다.
  • GitHub 저장소·Gist·게시물·외부 AI 서비스·SSH 서버의 데이터와 직접 내보낸 파일은 앱 제거로 삭제되지 않습니다. 해당 서비스나 파일 저장 위치에서 별도로 삭제해야 하며, Git 이력과 제공자 백업에 이전 내용이 남을 수 있습니다.

Firebase 자료는 제공자의 서비스별 보관·삭제 기준에 따라 처리됩니다. 관련 삭제 문의는 아래 연락처로 보내주세요. 앱 제거만으로 이미 전송된 진단·통계가 즉시 삭제되지는 않습니다.

개발자는 기기에만 있는 SSH 자격증명이나 작업 기록을 원격으로 열람·복구·삭제할 수 없습니다.
